# Agent Notice

This repository is the public release / test snapshot of
Glaze Ceremony: Promised Land.

It is not the authoritative development repository.

Agents performing development, debugging, implementation review,
architecture analysis, or current-source inspection must not treat
this repository as the canonical project source.

If the agent has authenticated access to the project's development
repository, use the canonical repository specified by that repository's
own agent instructions.

Use this repository only for:

- inspecting the published / test release;
- reproducing release-only issues;
- comparing public release behavior against development;
- checking packaging and player-facing files.

Do not infer current development state from this repository.

Do not propose source changes here unless the user explicitly asks to
modify the public release repository.
