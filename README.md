# Glaze Ceremony: Promised Land

A The Binding of Isaac: Repentance+ / REPENTOGON remaster of Glaze Ceremony.

This repository is the public release snapshot, not the development workspace.
Work-in-progress development may differ from the files published here.

This ZIP is the player-installable release. Copy the `Qing_remaster` folder into
your Isaac `mods` directory.

## ⚠ Alpha Testing Version

**Current version: alpha-0.1.1**

This is the first public Alpha test of *Glaze Ceremony: Promised Land*. It is not
a finished remaster.

**Current story content ends after the Prologue.**

alpha-0.1 includes the original Glaze Ceremony item and card content plus the
rework already finished, the new Prologue story, and character work that has
entered remaster and compatibility tuning. It does **not** open Chapter 1
(“What Is Sought”) or later story in normal play.

## What's included

- Original Glaze Ceremony item and card content, plus currently finished
  rework, fixes, and new systems
- The rebuilt Prologue story flow, including Ending 1 / Prologue unlocks
- Quest, story, UI, and infrastructure work that is already in a testable state
- Character remaster and compatibility work that has started (at different
  stages per character)

## What's not finished yet

- Chapter 1 and later story are still in development and are **not** available
  in the normal alpha-0.1 flow
- Character remaster is still in progress. Different characters are currently
  at different stages of refinement, compatibility work, and visual polish.
  **Tainted Qing currently has basic compatibility with vanilla items, but her
  aircraft skin system and compatibility with this mod's custom items and
  mechanics are still incomplete.** Character behavior, balance, compatibility,
  and presentation may continue to change throughout the Alpha period
- Visuals, balance, and compatibility may still change a lot

When Chapter 1, character compatibility and polish, and other major remaster
work meet a release bar, the mod is planned to return to Steam Workshop. Until
then, GitHub Alpha builds are the main public test channel. No date is
promised.

## 当前版本（中文）

**alpha-0.1** 是《琉璃盛典：应许之地》重制工程的首个公开 Alpha 测试版本。

这个版本主要用于公开测试已经完成重构或进入可测试阶段的内容。它并不代表整个模组的重制工作已经完成，部分系统、角色兼容、画面表现、数值与剧情仍会继续调整。

**当前故事内容截止于序章。** 第一章「所求之物」以及后续剧情仍在开发中，不会在当前 Alpha 的正常游玩流程中开放。

当前版本包含：原版《琉璃圣典》中已有的道具与卡牌内容，以及目前已经完成的新机制、修复与重构；新增并重构后的序章故事流程；当前已经完成重构的任务、剧情与部分公共系统；已进入重制流程的角色内容，以及目前已经完成的基础兼容调整。

角色重制仍在进行中。不同角色目前处于不同程度的精调、兼容与表现完善阶段。里小青当前已完成基础的原版道具兼容，但飞行器皮肤以及本模组道具与机制兼容仍未完成。Alpha 期间角色机制、数值、兼容性和表现仍可能继续调整。

第一章、角色兼容与精调，以及其他主要重制内容达到正式发布标准后，模组计划重新发布到 Steam Workshop。在此之前，GitHub 公开版本均属于 Alpha 测试版本，内容和行为仍可能发生较大变化。

开发阶段主要通过公开仓库的 GitHub Issues 接收 Bug、兼容性问题和其他游玩反馈。Steam 重新发布后，也计划继续保留这里作为较详细的问题反馈渠道。

如果游玩过程中发生崩溃，请尽量同时附上对应的日志文件和 `.dmp` 崩溃转储文件。两者一起提供通常更容易定位崩溃原因。
